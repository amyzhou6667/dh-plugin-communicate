# 技术债务记录

## 迭代1遗留问题

### TD-001: 搜索效率低下
- **文件**: `src/services/api_gateway.py:198-204`
- **问题**: `search_tasks_by_content` 方法先加载全部任务到内存，再在 Python 中过滤
- **影响**: 数据量大时性能差，内存消耗高
- **优先级**: 中
- **计划修复**: 迭代3或迭代4

### TD-002: 分页实现在应用层
- **文件**: `src/api/tasks.py:208-211`
- **问题**: 使用 Python 列表切片进行分页，每次都从数据库获取全部数据
- **影响**: 数据量大时性能差
- **优先级**: 中
- **计划修复**: 迭代3或迭代4

### TD-003: 飞书回调缺少签名验证
- **文件**: `src/webhook/feishu.py`
- **问题**: 没有验证飞书回调的签名，存在被伪造请求攻击的风险
- **影响**: 安全风险
- **优先级**: 高
- **计划修复**: 迭代4（飞书回调接收）

## 迭代2遗留问题

### TD-004: Harness 客户端缺少重试机制
- **文件**: `src/services/harness_client.py`
- **问题**: 网络请求失败后直接抛出异常，没有自动重试
- **影响**: 网络抖动时可能导致任务发现失败
- **优先级**: 中
- **建议**: 使用 `urllib3.Retry` 或 `tenacity` 库实现指数退避重试

### TD-005: 响应数据验证不足
- **文件**: `src/services/harness_client.py:71-72`
- **问题**: 没有验证返回的 JSON 结构是否符合预期
- **影响**: API 响应格式变化时可能导致运行时错误
- **优先级**: 低
- **建议**: 使用 `pydantic` 或 `marshmallow` 进行数据验证

### TD-006: 任务 ID 生成可能冲突
- **文件**: `src/services/task_discovery.py:47`
- **问题**: 使用 `task_{id}` 格式生成任务 ID，如果 id 包含特殊字符可能有问题
- **影响**: 可能导致数据库主键冲突
- **优先级**: 低
- **建议**: 使用 UUID 或更安全的 ID 生成方式

## 迭代3遗留问题

### TD-007: 飞书客户端缺少重试机制
- **文件**: `src/services/feishu_client.py`
- **问题**: 网络请求失败后直接抛出异常，没有自动重试
- **影响**: 网络抖动时可能导致消息发送失败
- **优先级**: 中
- **建议**: 使用 `urllib3.Retry` 或 `tenacity` 库实现指数退避重试

### TD-008: 令牌安全性
- **文件**: `src/services/feishu_client.py:39`
- **问题**: 令牌存储在内存中，如果进程被 dump 可能泄露
- **影响**: 安全风险
- **优先级**: 低
- **建议**: 考虑使用更安全的令牌存储方式（如加密内存）

### TD-009: 消息模板化
- **文件**: `src/services/feishu_message_formatter.py`
- **问题**: 卡片格式硬编码，不支持自定义模板
- **影响**: 灵活性不足
- **优先级**: 低
- **建议**: 支持自定义卡片模板，提高灵活性
